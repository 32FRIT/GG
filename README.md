# GG Football

## Structure

- `index.html` - main application entry point
- `css/app.css` - application styling
- `js/` - application runtime modules
- `data/` - player, coach, and card catalog data
- `assets/` - images, icons, flags, custom cards, and pack cards
- `packs/` - optional pack definitions
- `tools/card-maker.html` - custom player card creator
- `tests/` - smoke tests
- `sw.js` - offline and caching shell
